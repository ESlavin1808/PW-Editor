# 📝 PW Editor

![Python](https://img.shields.io/badge/Python-3.10%2B-blue)
![License](https://img.shields.io/badge/License-MIT-green)
![Platform](https://img.shields.io/badge/Platform-Windows-lightgrey)
![PyWry](https://img.shields.io/badge/UI-PyWry-8B5CF6)

**Локальный блочный редактор контента** в стиле WordPress Gutenberg.  
Работает на **PyWry** — Python + WebView (нативный браузерный движок).  
Данные хранятся в JSON, экспорт в HTML, Markdown и TXT.  
ИИ-интеграция через Mistral AI, OpenAI, Ollama, DeepSeek.

![PW Editor](app_icon_256.png)

## 🚀 Быстрый старт

### Требования
- Windows 10/11
- Python 3.10+

### Установка

```bash
# Клонировать
git clone https://github.com/your-username/PW-Editor.git
cd PW-Editor

# Виртуальное окружение (рекомендуется)
python -m venv venv
venv\Scripts\activate

# Установка зависимостей
pip install -r requirements.txt
```

### Запуск

**Без консоли (рекомендуется):**
```
PW Editor.vbs
```

**С консолью (для отладки):**
```
PW Editor.bat
```

**Напрямую:**
```bash
python app.py
```

## 🌟 Возможности

### Редактор
| Возможность | Описание |
|-------------|----------|
| 🧱 **Блочный редактор** | Параграфы, заголовки H2–H4, списки, цитаты, код, разделители, таблицы |
| 🖼️ **Изображения** | Вставка через медиатеку, перетаскивание, изменение размера |
| 📋 **Типы материалов** | Записи (📝), Новости (📰), Статьи (📄) с доп. полями |
| 🏷️ **Теги** | Категоризация материалов |
| ↩️ **Undo/Redo** | Ctrl+Z / Ctrl+Y, до 50 шагов |
| ✍️ **Проверка орфографии** | Встроенная, во всех текстовых блоках |
| 📊 **Счётчик слов** | В статус-баре под редактором |
| 📦 **Версионирование** | До 20 версий на материал, просмотр и восстановление |
| 🎯 **Режим фокуса** | Убирает интерфейс для работы без отвлечений |
| 👁️ **Предпросмотр** | Как материал будет выглядеть |
| 💾 **Автосохранение** | Через 2 секунды + при закрытии окна |

### ИИ-интеграция
- **Провайдеры:** OpenAI, Mistral AI, Ollama (локально), DeepSeek
- **Действия:** переписать, продолжить, исправить, сократить, перевести, объяснить
- **AI-чат** — свободный запрос с выбором провайдера/модели
- **Умные промпты** под тип материала
- **Безопасное хранение ключей** в Windows Credential Manager

### Импорт/Экспорт
- **Импорт:** Markdown (.md), TXT (.txt)
- **Экспорт:** HTML, Markdown, TXT, PDF (через печать браузера)

### Интерфейс
- 4 темы: Светлая, Тёмная, Современная, Газетная
- Боковая панель (список материалов с поиском и сортировкой)
- Панель настроек (инфо, AI, экспорт, тема)
- Поиск по названиям и содержимому
- Адаптивный дизайн

## 🔧 Настройка ИИ

1. Откройте правую панель (⚙️) → вкладка **AI**
2. Выберите провайдера: Mistral, OpenAI, Ollama или DeepSeek
3. Введите API-ключ (для Ollama не требуется) и URL
4. Нажмите **Загрузить модели**
5. Выберите модель из списка

> **Ollama:** URL по умолчанию `http://localhost:11434`, ключ не требуется.
> **Mistral:** URL `https://api.mistral.ai/v1`, ключ из [console.mistral.ai](https://console.mistral.ai)
> **OpenAI:** URL `https://api.openai.com/v1`, ключ из [platform.openai.com](https://platform.openai.com)

### AI-чат (нижняя панель)
- Выберите провайдера и модель
- Введите запрос → 🤖 → результат появится над строкой ввода
- **Вставить** — добавить результат в редактор
- **📥** — взять текст из текущего блока в поле запроса

## 🔒 Безопасность

API-ключи хранятся в **Windows Credential Manager** (через библиотеку `keyring`).  
В `settings.json` хранятся только URL и имя модели — ключ не сохраняется в открытом виде.  
Если `keyring` не установлен — ключ остаётся в памяти процесса до перезапуска.

## 🛠 Для разработчиков

### Технологии
- **PyWry** — Python + WebView (WebView2 на Windows)
- **HTML/CSS/JS** — рендеринг интерфейса (в одном файле `app.py`)
- **Python** — логика, JSON, AI API, экспорт
- **Pillow** — генерация иконок

### Расширение
- **Новый блок**: добавьте `case` в `collectContent()` и шаблон в `renderBlocks()`
- **Новый тип материала**: `option` в `#typeSelect` и `switchType()`
- **Новый провайдер AI**: в `#aiProvider`, `#aiProviderQuick` и `onProviderChange()`
