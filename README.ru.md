# 📝 PW Editor

![Python](https://img.shields.io/badge/Python-3.10%2B-blue)
![License](https://img.shields.io/badge/License-MIT-green)
![Platform](https://img.shields.io/badge/Platform-Windows-lightgrey)
![PyWry](https://img.shields.io/badge/UI-PyWry-8B5CF6)

**Локальный блочный редактор контента** в стиле WordPress Gutenberg.  
Работает на **PyWry** — Python + WebView (нативный браузерный движок).  
Данные хранятся в JSON, экспорт в HTML, Markdown и TXT.  
ИИ-интеграция через Mistral AI, OpenAI, Ollama, DeepSeek.

![PW Editor](app_icon_256.png)

---

## 🚀 Быстрый старт

### Требования
- Windows 10/11
- Python 3.10+

### Установка

```bash
# Клонировать
git clone https://github.com/your-username/PW-Editor.git
cd PW-Editor

# Виртуальное окружение (рекомендуется)
python -m venv venv
venv\Scripts\activate

# Установка зависимостей
pip install -r requirements.txt
```

### Запуск

**Без консоли (рекомендуется):**
```
PW Editor.vbs
```

**С консолью (для отладки):**
```
PW Editor.bat
```

**Напрямую:**
```bash
python app.py
```

## 🌟 Возможности

### Редактор

| Возможность | Описание |
|-------------|----------|
| 🧱 **Блочный редактор** | Параграфы, заголовки H2–H4, списки, цитаты, код, разделители, таблицы |
| 🖼️ **Изображения** | Вставка через медиатеку, перетаскивание, изменение размера |
| 🔄 **Drag & Drop блоков** | Перетаскивание блоков мышкой |
| 📋 **Типы материалов** | Записи (📝), Новости (📰), Статьи (📄) с доп. полями |
| 🏷️ **Теги** | Категоризация материалов |
| ↩️ **Undo/Redo** | Ctrl+Z / Ctrl+Y, до 50 шагов истории |
| ✍️ **Проверка орфографии** | Встроенная, во всех текстовых блоках |
| 📊 **Счётчик слов** | Количество слов, символов и блоков в статус-баре |
| 📦 **Версионирование** | До 20 версий на материал, просмотр и восстановление |
| 🎯 **Режим фокуса** | Убирает интерфейс для работы без отвлечений |
| 👁️ **Предпросмотр** | Как материал будет выглядеть в финале |
| 💾 **Автосохранение** | Через 2 секунды после изменений + при закрытии окна |
| 🔒 **Безопасность ключей** | API-ключи в Windows Credential Manager, не в JSON |

### Импорт

| Формат | Описание |
|--------|----------|
| **Markdown (.md)** | Парсинг заголовков, списков, цитат, кода, изображений |
| **TXT (.txt)** | Простой текст |

### Экспорт

| Формат | Описание |
|--------|----------|
| **HTML** | Стилизованная веб-страница |
| **Markdown** | С полной разметкой |
| **TXT** | Чистый текст без форматирования |
| **PDF** | Через печать браузера (Ctrl+P) |

### Интерфейс

- **4 темы оформления:** Светлая, Тёмная, Современная, Газетная
- **Боковая панель:** список материалов с поиском и сортировкой
- **Правая панель:** информация о материале, настройки AI, экспорт, тема
- **Поиск:** по названиям и по содержимому материалов
- **Сортировка:** по дате (новые/старые) и по алфавиту (А–Я / Я–А)
- **Адаптивный дизайн:** подстраивается под размер окна

## 🤖 ИИ-интеграция

### Поддерживаемые провайдеры

| Провайдер | URL по умолчанию | Ключ |
|-----------|------------------|------|
| **Mistral AI** | `https://api.mistral.ai/v1` | [console.mistral.ai](https://console.mistral.ai) |
| **OpenAI** | `https://api.openai.com/v1` | [platform.openai.com](https://platform.openai.com) |
| **Ollama** (локально) | `http://localhost:11434` | Не требуется |
| **DeepSeek** | `https://api.deepseek.com/v1` | [platform.deepseek.com](https://platform.deepseek.com) |

### Действия с текстом

- **Переписать** — улучшить стиль и грамматику
- **Продолжить** — дописать текст в том же стиле
- **Исправить** — орфография и грамматика
- **Сократить** — оставить главное
- **Перевести** — на выбранный язык (сетка языков)
- **Объяснить** — развёрнутое объяснение темы

### Умные промпты

AI автоматически адаптирует стиль под тип материала:

| Тип | Поведение |
|-----|-----------|
| 📝 **Запись** | Универсальный стиль |
| 📰 **Новость** | Кратко, 1–3 абзаца, с датой |
| 📄 **Статья** | Развёрнуто, с заголовками разделов, учитывает автора и рубрику |

### AI-чат (нижняя панель)

Компактная строка в нижней части редактора:
1. Выберите **провайдера** и **модель**
2. Нажмите **🔄** чтобы загрузить список моделей
3. Введите запрос в текстовое поле
4. **🤖** — отправить, результат появится над строкой
5. **📋 Вставить** — добавить результат в редактор
6. **📥** — взять текст из текущего блока в поле запроса

## 🔒 Безопасность

API-ключи хранятся в **Windows Credential Manager** через библиотеку `keyring`.  
В файле `settings.json` хранятся только URL провайдеров и имена моделей — ключи не сохраняются в открытом виде.  
Если `keyring` не установлен — ключ остаётся только в памяти процесса до перезапуска.

## 🛠️ Для разработчиков

### Технологии

| Компонент | Технология |
|-----------|------------|
| **Фреймворк** | PyWry (WebView2 на Windows) |
| **Интерфейс** | HTML + CSS + JavaScript (в одном файле) |
| **Логика** | Python (JSON, AI API, экспорт) |
| **Иконки** | Pillow (опционально) |
| **Безопасность** | keyring (Windows Credential Manager) |

### Архитектура

Приложение состоит из одного файла `app.py` (~3800 строк), который содержит:

1. **HTML-шаблон** — весь интерфейс (Python raw-строка)
2. **CSS** — стили, 4 темы через CSS-переменные
3. **JavaScript** — логика редактора, блоков, AI, экспорта
4. **Python-колбэки** — обработка запросов из JS (сохранение, загрузка, AI API)

### Как расширить

- **Новый тип блока**: добавьте `case` в `collectContent()` и шаблон в `renderBlocks()`
- **Новый тип материала**: добавьте `<option>` в `#typeSelect` и обработайте в `switchType()`
- **Новый провайдер AI**: добавьте в `<select id="aiProvider">`, `#aiProviderQuick` и пропишите в `PROVIDERS`
